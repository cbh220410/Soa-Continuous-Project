# Projectname1

Standalone Spring Boot and JPA sample application. It runs on port `1119` and uses the H2 database dependencies declared in its Maven configuration.

There are currently no controller endpoints in this module; it is kept as an independent application example.

## Run

```powershell
.\mvnw.cmd spring-boot:run
```

Run the module tests with:

```powershell
.\mvnw.cmd test
```
